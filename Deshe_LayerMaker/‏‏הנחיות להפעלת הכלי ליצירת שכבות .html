מדריך למשתמש - Deshe_LayerMaker

כלי אוטומטי ליצירת שכבות והגדרת דומיינים ב-ArcGIS Pro

הנחיות להפעלת הכלי

  1. חילוץ התיקייה: חלץ את התיקייה המכילה את הכלי למחשב המקומי.
  2. פתיחת פרויקט: פתח פרויקט ב-ArcGIS Pro (וודא שקיימת מפה פעילה בפרויקט).
  3. ייבוא הטולבוקס: דרך חלון ה-Catalog, לחץ מקש ימני על Toolboxes -> Add Toolbox ונווט לקובץ: DesheTools\execution_scripts\DesheTools.atbx
  4. פתיחת הכלי: הפעל את הכלי create new layer.
  5. הזנת פרמטרים:
    • Layer Name: בחר את שם השכבה מתוך רשימת השכבות המוגדרות.
    • Domain Mode: בחר את אופן הטיפול בדומיינים קיימים (ברירת מחדל: skip).
  6. סיום ההרצה ותוצרים:
    • השכבה תיווצר ב-Geodatabase של ברירת המחדל (Default GDB) ברשת Israel TM Israel (EPSG:2039).
    • השכבה תתווסף אוטומטית למפה הפעילה.

מצבי עדכון דומיינים (Domain Mode)

מצב (Mode) תיאור התנהגות המערכת
skip (ברירת מחדל) אם הדומיין כבר קיים ב-GDB, הכלי מדלג עליו ולא מבצע שינויים.
update מעדכן דומיינים קיימים במידה ונוספו ערכים חדשים בקובץ הקונפיגורציה.
report מציע דוח שינויים בלבד בחלון ה-Messages (חדש, הוסר, שונה) ללא ביצוע שינויים בפועל.
⚙️ ניהול הגדרות ושדות (Configuration) הגדרות השכבות, סוגי הגיאומטריה, השדות והדומיינים נשלטות באופן דינמי דרך קבצי ה-Excel הממוקמים בתיקייה: DesheTools\configuration\fields.xlsx DesheTools\configuration\domains.xlsx
שינויים שבוצעו בגרסה האחרונה 220225
  • הוספת ערכים חדשים לדומיין zoology_survey.
  • עדכון שם השדה ל: "מספר גלאי/מצלמה/גלאי/נקודת דיגום".
  • הוספת שדה חדש Completed בשכבות הערות קויות/נקודתיות סוקר עם דומיין כן/לא (Binaries).
  • תמיכה במנגנון עדכון דומיינים מבוסס אקסל כולל מצבי update ו-report.
⚠️ טיפ לעבודה עם GDB קיים: כאשר עובדים מול GDB המכיל דומיינים מהרצה קודמת, מומלץ להגדיר את הפרמטר Domain Mode כ-update כדי לקבל את ערכי הדומיין המעודכנים ביותר.
