הנחיות ועדכוני גרסה אחרונים

הנחיות להפעלת הכלי

  1. חילוץ התיקייה: חלץ את התיקייה המכילה את הכלי למחשב.
  2. פתיחת פרויקט: פתח פרויקט ב-ArcGIS Pro (פרויקט קיים או חדש).
  3. ייבוא הטולבוקס: ייבא דרך חלון ה-Catalog את הקובץ: DesheTools\execution_scripts\DesheTools.atbx *(לפני ההרצה – יש לוודא שבפרויקט הנוכחי קיימת מפה פעילה)*
  4. פתיחת הסקריפט: פתח את הסקריפט create new layer.
  5. בחירת השכבה: בחר את השכבה אותה תרצה להוסיף והרץ את הסקריפט.
  6. סיום ההרצה:
    • השכבה תיווצר ב-GDB שמוגדר כברירת מחדל (Default GDB).
    • השכבה תתווסף אוטומטית למפה הפעילה בפרויקט.
    • חשוב: יש לשנות את שמות השכבות לשם ייחודי עבור הפרויקט (למשל: סקר מישורי הלס_2026).
