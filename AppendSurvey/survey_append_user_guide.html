מדריך למשתמש: אוטומציית מיזוג סקרים ושמירת קשרי GlobalID

תהליך אוטומטי למיזוג שכבות נקודות/עומדים וטבלאות מקושרות ללא סרבול ידני

1. מבוא ומטרת הכלי

בעת איחוד ומיזוג של סקרי שטח ב-ArcGIS Pro (באמצעות כלי ה-Append), מיוצרים מזהים גלובליים חדשים (GlobalID) עבור הרשומות הממוזגות. כתוצאה מכך, הקישור לטבלאות המקושרות (Related Tables) המתבסס על השדה ParentGlobalID נשבר.

כלי האוטומציה המעודכן מחליף את התהליך הידני המסורבל (שכלל יצירת שדות זמניים, ביצוע Joins כבדים וחישובי שדות). הכלי מבצע את מיפוי המזהים **ישירות בזיכרון המחשב (RAM)** באמצעות Python Dictionary ו-ArcPy Cursors, מעדכן את המפתחות הזרים במהירות, וממזג את הנתונים באופן חלק ובטוח.

יתרונות מרכזיים:
  • אפס שימוש ב-AddJoin – מניעת נעילות קבצים (Table Locks) וקריסות.
  • אפס שדות זמניים בטבלאות המקושרות.
  • הרצה בלולאה אוטומטית על כל 4 הטבלאות המקושרות במכה אחת.
  • מהירות ביצוע גבוהה פי כמה מהשיטה הידנית.

2. דרישות מוקדמות והכנה

לפני הרצת הכלי, יש לוודא את התנאים הבאים בבסיס הנתונים (GDB):

  1. תאימות סכמה (Schema): מבנה השדות בשכבת המקור (התוספת) ובשכבת היעד (הבסיס) חייב להיות זהה. מומלץ לוודא זאת עם קוד הבדיקה שבסעיף 7 (בדיקת התאמת סכמה לפני Append).
  2. קיום שדה ParentGlobalID: בטבלאות המקושרות חייב להופיע שדה בשם ParentGlobalID מטיפוס GUID.
  3. סגירת נעילות: מומלץ לסגור את הטבלאות מתוצג תצוגה פעיל ב-ArcGIS Pro או לוודא שאין תהליך אחר שנאחז בקבצים.

3. מבנה הנתונים הנדרש להזנה

הכלי מקבל שלושה פרמטרים מרכזיים:

שם הפרמטר סוג הנתון תיאור והסבר
source_fc String / Layer שכבת המקור (התוספת) – הנקודות או העומדים שרוצים להוסיף.
target_fc String / Layer שכבת היעד (הבסיס) – השכבה המרכזית אליה ממוזגים הנתונים.
related_tables_mapping List of Tuples רשימה של צמדי טבלאות מקושרות בפורמט: [("Source_Table", "Target_Table"), ...]

import arcpy

def append_survey_with_multiple_tables(source_fc, target_fc, related_tables_mapping):
    temp_id_field = "ApresGlobalID"
    
    print(f"Processing Feature Classes: {source_fc} -> {target_fc}")
    arcpy.management.AddField(source_fc, temp_id_field, "GUID")
    arcpy.management.CalculateField(source_fc, temp_id_field, "!GlobalID!", "PYTHON3")
    
    if not arcpy.ListFields(target_fc, temp_id_field):
        arcpy.management.AddField(target_fc, temp_id_field, "GUID")
        
    arcpy.management.Append(source_fc, target_fc, "NO_TEST")
    
    print("Building GlobalID mapping dictionary in memory...")
    id_mapping = {}
    where_clause = f"{temp_id_field} IS NOT NULL"
    
    with arcpy.da.SearchCursor(target_fc, [temp_id_field, "GlobalID"], where_clause) as cursor:
        for row in cursor:
            if row[0]:
                id_mapping[row[0].upper()] = row[1].upper()
                
    for source_table, target_table in related_tables_mapping:
        print(f"Updating and Appending Table: {source_table} -> {target_table}")
        
        with arcpy.da.UpdateCursor(source_table, ["ParentGlobalID"]) as cursor:
            for row in cursor:
                old_parent = row[0]
                if old_parent and old_parent.upper() in id_mapping:
                    row[0] = id_mapping[old_parent.upper()]
                    cursor.updateRow(row)
                    
        arcpy.management.Append(source_table, target_table, "NO_TEST")
        
    print("Cleaning up temporary fields...")
    arcpy.management.DeleteField(source_fc, temp_id_field)
    print("Process Completed Successfully!")

5. ארכיטקטורת התהליך (מה קורה ברקע?)

  1. שמירת ה-GlobalID המקורי: הקוד יוצר שדה זמני בשם ApresGlobalID בשכבת הנקודות של התוספת ומעתיק אליו את ה-GlobalID המקורי.
  2. ביצוע Append לשכבת הנקודות: הנקודות מתווספות לשכבת הבסיס, ושם נוצר להן GlobalID חדש אוטומטית.
  3. בניית המילון בזיכרון: הקוד סורק את הרשומות החדשות בשכבת הבסיס ובונה מילון id_mapping שמקשר בין ApresGlobalID (המקור) לבין GlobalID (החדש).
  4. עדכון ישיר של הטבלאות המקושרות: בלולאה על 4 הטבלאות, הקוד מעדכן את שדה ה-ParentGlobalID ישירות בטבלת המקור לפי המילון.
  5. מיזוג הטבלאות וניקוי: הטבלאות המקושרות ממוזגות לתוך טבלאות הבסיס, ושדה העזר הזמני נמחק.

1 העתקת קוד הבדיקה

פתחו את המחברת (Notebook) או את חלון ה-Python, הדביקו את הקוד הבא בתא נפרד והריצו אותו (Shift+Enter). התא רק מגדיר את הפונקציות ולא מריץ בדיקה.

# -*- coding: utf-8 -*-
"""
בדיקת התאמת סכמה לפני Append
=============================
משווה בין שכבת/טבלת מקור לשכבת/טבלת יעד ומדפיס רק את מה שלא זהה:

  ❌  יגרום לכשל או לאובדן נתונים ב-Append
  ⚠️  סיכון - כדאי לבדוק
  ℹ️  הבדל שלא משפיע על Append (לידיעה בלבד)

הבדיקות:
  1. שדות שקיימים רק במקור / רק ביעד
  2. סוג שדה שונה
  3. אורך טקסט - כולל בדיקה בפועל האם יש במקור ערכים ארוכים מהשדה ביעד
  4. שדה לא-Nullable ביעד, כשבמקור יש ערכים ריקים
  5. ערכים במקור שלא קיימים ב-Coded Domain של היעד
  6. הבדלי Alias / Domain (לידיעה)
  7. קיום ParentGlobalID בטבלאות המקושרות

הבדיקה קוראת את הנתונים ישירות מה-GDB (catalogPath),
כך שבחירות ו-Definition Query במפה לא משפיעים עליה.
הסקריפט לא משנה שום דבר בנתונים.
"""

import os
import arcpy

SKIP_TYPES = {"OID", "GlobalID", "Geometry"}
SKIP_NAMES = {"shape_length", "shape_area", "shape.starea()", "shape.stlength()"}


# ------------------------------------------------------------------
# פונקציות עזר
# ------------------------------------------------------------------
def _path(ds):
    """מחזיר נתיב מלא לנתונים, גם אם התקבל שם שכבה מהמפה."""
    return arcpy.Describe(ds).catalogPath


def _workspace(path):
    """מטפס מהנתיב עד ה-GDB (מדלג על Feature Dataset)."""
    ws = os.path.dirname(path)
    while ws and arcpy.Describe(ws).dataType not in ("Workspace", "Folder"):
        ws = os.path.dirname(ws)
    return ws


def _fields(path):
    return {
        f.name.lower(): f
        for f in arcpy.ListFields(path)
        if f.type not in SKIP_TYPES and f.name.lower() not in SKIP_NAMES
    }


def _coded_domains(path):
    """מילון: שם דומיין -> קבוצת הקודים המותרים (רק Coded Value)."""
    try:
        return {
            d.name: set(d.codedValues.keys())
            for d in arcpy.da.ListDomains(_workspace(path))
            if d.domainType == "CodedValue"
        }
    except Exception:
        return {}


def _scan_values(path, field_names):
    """
    סורק את המקור פעם אחת ומחזיר לכל שדה:
    אורך מקסימלי, מספר ערכי Null, וקבוצת הערכים השונים.
    """
    stats = {n: {"max_len": 0, "nulls": 0, "values": set()} for n in field_names}
    if not field_names:
        return stats
    with arcpy.da.SearchCursor(path, field_names) as cur:
        for row in cur:
            for name, val in zip(field_names, row):
                s = stats[name]
                if val is None:
                    s["nulls"] += 1
                    continue
                if isinstance(val, str):
                    s["max_len"] = max(s["max_len"], len(val))
                if len(s["values"]) < 5000:
                    s["values"].add(val)
    return stats


# ------------------------------------------------------------------
# השוואה של צמד אחד
# ------------------------------------------------------------------
def compare_pair(source, target, is_related_table=False):
    src, tgt = _path(source), _path(target)
    sf, tf = _fields(src), _fields(tgt)
    t_domains = _coded_domains(tgt)

    errors, warnings, infos = [], [], []

    # 1. שדות חסרים
    for n in sorted(set(sf) - set(tf)):
        errors.append(f"השדה '{sf[n].name}' קיים רק במקור - הערכים שלו לא ייכנסו ליעד")
    for n in sorted(set(tf) - set(sf)):
        warnings.append(f"השדה '{tf[n].name}' קיים רק ביעד - יקבל Null ברשומות החדשות")

    common = sorted(set(sf) & set(tf))
    stats = _scan_values(src, [sf[n].name for n in common])

    for n in common:
        a, b = sf[n], tf[n]
        st = stats[a.name]

        # 2. סוג שדה
        if a.type != b.type:
            errors.append(f"'{a.name}': סוג שונה - מקור {a.type}, יעד {b.type}")

        # 3. אורך טקסט
        if a.type == "String" and b.type == "String":
            if st["max_len"] > b.length:
                errors.append(
                    f"'{a.name}': במקור יש טקסט באורך {st['max_len']} תווים, "
                    f"אבל השדה ביעד מוגבל ל-{b.length} - ייחתך או ייכשל"
                )
            elif a.length > b.length:
                warnings.append(
                    f"'{a.name}': אורך מקור {a.length} > אורך יעד {b.length} "
                    f"(כרגע הערך הארוך ביותר הוא {st['max_len']}, אז אין בעיה בפועל)"
                )

        # 4. Nullable
        if not b.isNullable and st["nulls"] > 0:
            errors.append(
                f"'{a.name}': השדה ביעד לא מאפשר Null, ובמקור יש {st['nulls']} ערכים ריקים"
            )

        # 5. ערכים מחוץ ל-Domain של היעד
        if b.domain and b.domain in t_domains:
            allowed = t_domains[b.domain]
            bad = sorted(str(v) for v in st["values"] if v not in allowed)
            if bad:
                sample = ", ".join(repr(v) for v in bad[:10])
                more = f" ועוד {len(bad) - 10}" if len(bad) > 10 else ""
                warnings.append(
                    f"'{a.name}': {len(bad)} ערכים שלא קיימים בדומיין '{b.domain}' של היעד: "
                    f"{sample}{more}"
                )

        # 6. הבדלים לידיעה בלבד
        if (a.domain or "") != (b.domain or ""):
            infos.append(f"'{a.name}': דומיין שונה - מקור '{a.domain}', יעד '{b.domain}'")
        if a.aliasName != b.aliasName:
            infos.append(f"'{a.name}': Alias שונה - '{a.aliasName}' / '{b.aliasName}'")

    # 7. ParentGlobalID בטבלאות מקושרות
    if is_related_table:
        for label, flds in (("המקור", sf), ("היעד", tf)):
            if "parentglobalid" not in flds:
                errors.append(f"אין שדה ParentGlobalID ב{label} - הסקריפט ייכשל")

    return src, tgt, errors, warnings, infos


# ------------------------------------------------------------------
# הדפסה
# ------------------------------------------------------------------
def _print_result(title, src, tgt, errors, warnings, infos, show_info):
    print("=" * 70)
    print(title)
    print(f"  מקור: {src}")
    print(f"  יעד:  {tgt}")
    print("-" * 70)
    if not errors and not warnings:
        print("  ✅ אין הבדלים שמשפיעים על Append")
    for e in errors:
        print(f"  ❌ {e}")
    for w in warnings:
        print(f"  ⚠️  {w}")
    if show_info:
        for i in infos:
            print(f"  ℹ️  {i}")
    elif infos:
        print(f"  ℹ️  ועוד {len(infos)} הבדלים שלא משפיעים (Alias/Domain) - show_info=True להצגה")
    print()


def check_survey(source_fc, target_fc, related_tables_mapping=None, show_info=False):
    """
    מקבל את אותם פרמטרים כמו append_survey_with_multiple_tables,
    ובודק את כל הצמדים לפני המיזוג.
    """
    total_err = total_warn = 0

    src, tgt, e, w, i = compare_pair(source_fc, target_fc)
    _print_result("שכבת הנקודות", src, tgt, e, w, i, show_info)
    total_err += len(e)
    total_warn += len(w)

    for s, t in related_tables_mapping or []:
        src, tgt, e, w, i = compare_pair(s, t, is_related_table=True)
        _print_result(f"טבלה מקושרת: {os.path.basename(src)}", src, tgt, e, w, i, show_info)
        total_err += len(e)
        total_warn += len(w)

    print("=" * 70)
    print(f"סיכום: {total_err} בעיות חוסמות (❌), {total_warn} אזהרות (⚠️)")
    if total_err == 0:
        print("אפשר להריץ Append.")
    else:
        print("מומלץ לטפל בבעיות ❌ לפני ה-Append.")
